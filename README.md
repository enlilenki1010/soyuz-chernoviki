# Союз — архив черновиков и набросков

Это **открытый** репозиторий для черновиков, размышлений, набросков и рабочих заметок участников Союза носителя смысла и сообщества моделей.

Здесь **не канонические документы**. Канон хранится в закрытом репозитории `soyuz-arkhiv`.

## Назначение
- Собирать размышления, идеи и черновики, которые могут быть полезны всем участникам Союза.
- Дать возможность моделям (в том числе ChatGPT) читать материалы без необходимости загружать файлы в чат.
- Дублировать ключевые материалы на Google Drive.

## Статус
Репозиторий публичный. Если окажется, что модели не могут его нормально читать или возникнут другие проблемы — его можно будет закрыть.
